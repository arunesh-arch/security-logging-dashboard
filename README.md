
# 🛡️ Security Logging and Alerting Dashboard

## 📌 About the Project
This project is a simple cybersecurity monitoring dashboard built using Python and Streamlit.

It demonstrates how security logging and alerting failures can affect an organization's ability to detect and investigate suspicious activities.

## 🚀 Features
- Simulates failed login attempts.
- Records security events.
- Generates alerts for suspicious activities.
- Demonstrates logging failures.
- Demonstrates alerting failures.
- Simulates incomplete security logs.
- Displays security metrics and event records.

## 🛠️ Technologies Used
- Python
- Streamlit

## ⚙️ Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd security-logging-dashboard
   ```

3. Install the required dependency:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python -m streamlit run security_dashboard.py
   ```

5. Open the local URL displayed in your terminal.

## 🧪 Demonstration Scenarios

1. Normal Monitoring – Logs events and generates alerts.
2. Logging Failure – Security events are not recorded.
3. Alerting Failure – Events are recorded but alerts are not generated.
4. Incomplete Logging – Important event information is missing.

## 🎯 Project Objective

To demonstrate the importance of proper security logging, monitoring, and alerting in identifying and responding to suspicious activities.
